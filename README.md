# 倉庫番演習（Sokoban Exercise）

## ゲームの概要

荷物を押してすべての目的地に運ぶ、コンソール版の倉庫番ゲームです。
配布ゲームをベースに、機能の追加・改良を行いました。

## 動作環境

- OS：Windows 11
- Python：3.12
- 必要なライブラリ：追加ライブラリ不要

## インストール方法

```bash
git clone https://github.com/amritbasnet1112-cell/sokoban-exercise.git
cd sokoban-exercise
```

## 起動方法

```bash
python sokoban_exercise.py
```

## 操作方法

`操作 >` と表示されたら、キーを入力して Enter を押します。

- 【w / a / s / d】：【上 / 左 / 下 / 右に移動】
- u：1手戻す
- r：ステージを最初からやり直す
- q：ゲーム終了

クリア条件：【すべての荷物を目的地に運ぶ】
