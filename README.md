# 倉庫番演習（Sokoban Exercise）

## ゲームの概要

荷物（箱）を押して、すべてのゴールに運ぶコンソール版の倉庫番ゲームです。
第13回の倉庫番演習（配布ゲーム）をベースに、機能の追加・改良を行いました。全4ステージで、各ステージには手数制限があります。

## 動作環境

- OS：Windows 11
- Python：3.12
- 必要なライブラリ：追加ライブラリ不要

## インストール方法

```bash
git clone https://github.com/amritbasnet1112-cell/sokoban-exercise.git
cd sokoban-exercise
```

## 起動方法

```bash
python sokoban_exercise.py
```

## 操作方法

`操作 >` と表示されたら、キーを入力して Enter を押します。

- W / A / S / D：上 / 左 / 下 / 右に移動
- u：1手戻す
- r：ステージを最初からやり直す
- q：ゲーム終了

クリア条件：すべての荷物を目的地に運ぶ。

## 追加・改良した機能

### 改良機能01：ステージ4の追加

新しいステージ（ステージ4）を追加しました。箱2個・ゴール2個の盤面で、ステージ3クリア後に遊べます。全4ステージをクリアするとゲーム終了です。

### 改良機能02：ステージごとの手数制限

各ステージに最大手数（ステージ1〜4：10・20・30・25手）を設定しました。手数が上限に達してもクリアできていない場合は「手数オーバー」と表示され、そのステージを最初からやり直します。最後の1手でクリアした場合はクリア扱いになります。

### 改良機能03：残り手数の表示

盤面の下に、移動回数と一緒に残り手数を `移動回数: 3 (残り 7)` の形式で表示します。手数制限の中で、あと何手動けるかを確認しながらプレイできます。

### 改良機能04：クリア評価と合計手数の表示

ステージクリア時に、使用した手数と制限手数を表示し、手数の少なさに応じて★の評価（制限の50%以内なら★3、80%以内なら★2、それ以上は★1）を表示します。全ステージクリア時には、合計手数を表示します。
