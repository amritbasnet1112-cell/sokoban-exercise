# 倉庫番（Sokoban）演習版

Python（標準ライブラリのみ）で作ったテキスト版の倉庫番パズルです。
すべての箱（`$`）をゴール（`.`）へ押して運ぶとステージクリアです。箱は押せますが、引くことはできません。

第13回の演習ファイル `sokoban_exercise.py` を完成させ、機能を追加しました。

## 起動方法

```bash
python sokoban_exercise.py
```

Python 3 が必要です。追加パッケージは不要です。

## 操作方法

| キー | 動作 |
|---|---|
| W / A / S / D + Enter | 上 / 左 / 下 / 右へ移動 |
| U + Enter | 1手戻す |
| R + Enter | ステージをやり直す |
| Q + Enter | 終了 |

## マップの記号

| 記号 | 意味 |
|---|---|
| `#` | 壁 |
| `.` | ゴール |
| `$` | 箱 |
| `@` | プレイヤー |
| `*` | ゴール上の箱 |
| `+` | ゴール上のプレイヤー |

## 変更内容

### 第1部：TODO の実装
- **TODO 1 プレイヤー移動：** `apply_move` で WASD のキーから移動の差分を取り出し、`next_position` で次の座標を計算してプレイヤーを動かします。盤面の外へは出られません。
- **TODO 2 壁判定：** `can_enter` は、移動先が盤面内で、かつ壁の集合 `board["solid"]` に含まれないときだけ True を返します。
- **TODO 3 箱を押す処理：** `push_crate` で箱の一つ先を調べます。壁・盤面外・別の箱があれば何も変更せず、プレイヤーも動きません。
- 一手戻す機能のため、押す前に箱の集合の `.copy()` を履歴に保存しています。コピーしないと、履歴と現在の箱が同じ集合を指してしまい、正しく戻せません。

### 第2部：自分で追加した機能
- **ステージ追加：** 新しいステージマップ（`MAP_TEXT`）を追加しました。
- **手数制限：** ステージごとに上限手数（`MOVE_LIMITS = [10, 20, 30, 25, 35]`）を設定しました。画面に残り手数を表示し、上限に達するとステージをやり直します。クリア判定を先に行うので、最後の1手でクリアした場合は成功扱いです。
